# Florecer en la Oscuridad

## Descripción
Juego de aventuras 2D con un estilo visual cálido y acogedor.

## Características
- Movimiento del personaje con W, A, S, D
- Sistema de diálogo con progreso emocional
- Mini-juego de carreras
- Mapas generados dinámicamente

## Configuración
- Unity 2023.1 o superior
- .NET 4.x
- Soporte 2D activado
